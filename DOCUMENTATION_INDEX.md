1. Leer [README.md](README.md) - 20 min

3. Generar un anuncio - 15 min
4. Explorar características - 30 min

3. Implementar nuevas features - 180 min
4. Escribir tests - 60 min
5. Desplegar - 60 min
6. Monitoreo - 60 min
