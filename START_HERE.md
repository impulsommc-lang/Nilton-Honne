
## 📦 Stack Tecnológico

- **Frontend**: React 19 + TypeScript
- **Build**: Vite
- **Styling**: Tailwind CSS v4
- **Animaciones**: Framer Motion
- **AI**: Google Gemini 2.5 Flash Image
- **Icons**: Lucide React

## 🚀 Deploy en 3 Clicks

1. **Push a GitHub**
   ```bash
   git push origin main
   ```

2. **Conecta a Vercel**
   - Ve a [vercel.com](https://vercel.com)
   - Importa tu repositorio

3. **Configura Variables**
   - Añade `GEMINI_API_KEY` en Environment Variables

✅ **¡Deployado automáticamente!**

> Más detalles en [DEPLOYMENT.md](DEPLOYMENT.md)

## 🆘 Troubleshooting Rápido

### API Key error
```bash
# Verifica que .env.local tiene:
GEMINI_API_KEY=tu_clave_aqui
```

### Problema en móvil
```bash
# Limpia caché
Ctrl+Shift+Del
# Recarga
F5
```

### Build falla
```bash
npm run clean
npm install
npm run build
```
