# Guía Rápida de Solución - Error "No se pudo generar el anuncio"

## En 2 Minutos

### Si ves este error:
> "Error al generar el anuncio. Asegúrate de que las imágenes sean válidas y no demasiado pesadas."

### Hazlo AHORA:

1. **Verifica que cargaste UNA imagen** (mínimo)
   - Panel izquierdo debe mostrar al menos 1 imagen con preview

2. **Comprueba el tamaño**: 
   - Cada imagen debe ser < 5 MB
   - Si no sabe, usa TinyPNG.com para comprimir

3. **Verifica el formato**:
   - ✓ JPG/JPEG
   - ✓ PNG
   - ✓ WebP
   - ✗ Cualquier otra cosa

4. **Intenta con otra imagen**
   - A veces una imagen específica es problemática

5. **Si sigue fallando**:
   - Recarga la página (Ctrl+R o Cmd+R)
   - Intenta en otro navegador

| Error que ves | Causa | Solución |
|---|---|---|
| "El archivo es demasiado grande" | Imagen > 5 MB | Usa TinyPNG.com |

## Soluciones Rápidas (Elige la tuya)

### Problema: Imagen muy grande

**Opción A - Online (1 minuto)**:
1. Ve a TinyPNG.com
2. Arrastra tu imagen
3. Descarga comprimida
4. Sube a la app

**Opción B - Fotógrafo (2 minutos)**:
1. Ve a Pixlr.com
2. Open Image → Tu foto
3. Image → Scale
4. Ancho a 1500px
5. Download

### Problema: Formato incorrecto

**Opción A - Online Converter**:
1. CloudConvert.com
2. Sube tu archivo
3. Selecciona JPEG
4. Download

**Opción B - Software**:
- Mac: Preview (abre > File > Export > JPEG)
- Windows: Paint (File > Save As > JPG)

### Problema: Sigue sin funcionar

1. Cierra completamente el navegador
2. Limpia cache:
   - Chrome: Settings > Privacy > Clear browsing data
3. Abre de nuevo
4. Intenta
